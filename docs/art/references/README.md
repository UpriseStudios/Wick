## Rules

- New versions get a new file (`_v2`), never an overwrite, so earlier prompts
  and decisions stay traceable.
- These are concept references, not game assets. Final models, textures and the
  vector wordmark are built from them (see `docs/asset-production.md`).
- Track the PNGs with Git LFS if the repo uses it.
